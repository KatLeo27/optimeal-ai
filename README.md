## 1. Project Overview
**OptiMeal AI** is an end-to-end AI-powered decision-support platform designed for large-scale institutional food-service organizations (corporate cafeterias, university dining halls, hospital nutrition services, hotels, and institutional catering centers).

The platform addresses avoidable food overproduction and kitchen waste by combining **Machine Learning Demand Forecasting**, **Dynamic Safety Margin Optimization**, **Statistical & Unsupervised Anomaly Detection**, **Rule-Grounded Automated Operational Insights**, and a **Retrieval-Augmented Generation (RAG) Sustainability Knowledge Assistant**.

---

## 2. Problem Statement
Large institutional dining operations face fluctuating attendance and erratic portion demand due to shifting day-of-week schedules, weather variations, academic/corporate calendar events, and dietary preferences. 

Historically, kitchen managers compensate by preparing food with fixed, generous safety buffers (often **10–15% blind overproduction**). This practice results in substantial volumes of unserved edible food waste, heavy financial losses from spoiled ingredients, unnecessary kitchen labor costs, and avoidable greenhouse gas emissions ($CH_4$ and $CO_2$) in municipal landfills.

## 5. Core Solution Features
1. **Executive Operations Center:** Real-time visibility into total waste weight ($kg$), financial cost loss ($\$$), daily waste trends, and overproduction surplus rates.
2. **Granular Waste Intelligence:** Categorical breakdowns by food stream (Meat, Rice, Vegetables, Soup) and canteen quadrants.
3. **ML Demand Forecasting:** Pre-service prediction of consumed portions based on attendance headcount, weather forecasts, and calendar indicators.
4. **Intelligent Kitchen Prep Optimizer:** Dynamic safety buffer calibration (3–8%) replacing blind fixed overproduction while preventing stockouts.
5. **What-If Scenario Simulator:** Interactive simulation testing the environmental and financial impact of weather shifts, schedule changes, and manual kitchen overrides.
6. **Automated Operational Insights:** Natural-language rule-grounded observations derived from actual operational distributions.
7. **RAG Sustainability Assistant:** Knowledge-base assistant querying verified EPA Food Recovery Hierarchy and institutional prevention guidelines with explicit source citations.
8. **Responsible AI Framework:** Comprehensive governance documenting ethics, human-in-the-loop oversight, fairness, and data lineage.

## 7. Dataset Lineage & Provenance

To uphold strict **Responsible AI** standards, the dataset explicitly distinguishes three layers of data:

1. **Authentic Source Data (`data/raw/Dataset Propely.csv`):**
   - 2,600 authentic operational records spanning 61 distinct service dates (June 11, 2025 to August 10, 2025).
   - Real columns: `Date`, `Meal` (Breakfast, Lunch, Dinner), `Canteen_Section` (A, B, C, D), `Food_Category` (Meat, Rice, Soup, Vegetables), `Waste_Weight_kg` ($0.1$ to $5.0$ kg), `Unit_Price_per_kg`, `Cost_Loss` ($\$).

2. **Derived Features (Deterministic):**
   - `Day_of_Week`, `Is_Weekend`, `Month`, `Day`, `Day_of_Year`, `Cost_Loss` validation.

3. **Synthetic Augmented Features (`data/processed/food_waste_processed.csv`):**
   - Grounded operational features generated with a fixed seed (`seed=42`) to simulate pre-service gate headcounts, weather telemetry, and lagged consumption:
   - `expected_attendance`, `actual_attendance`, `meals_prepared`, `meals_consumed` *(Target)*, `previous_day_consumption`, `temperature`, `rainfall`, `special_event`, `holiday`.

*See `data/README.md` for complete mathematical and statistical definitions.*

## 8. Machine Learning Methodology & Evaluation

### Modeling Formulation
- **Target Variable:** `meals_consumed` (Actual portions eaten by diners).
- **Features Known Prior to Prep:** `Meal`, `Food_Category`, `Canteen_Section`, `Day_of_Week`, `expected_attendance`, `temperature`, `rainfall`, `holiday`, `special_event`, `previous_day_consumption`, `Is_Weekend`, `Month`, `Day`.
- **Pre-processing:** `ColumnTransformer` with `OneHotEncoder(handle_unknown='ignore')` and `StandardScaler()`.

### Benchmark Results (Held-out 20% Test Set)

| Architecture | Test MAE | Test RMSE | Test $R^2$ Score | Selection Status |
| :--- | :---: | :---: | :---: | :---: |
| **Linear Regression (Baseline)** | **15.09** | **20.47** | **0.9868** | **Selected Best Model** |
| **Gradient Boosting Regressor** | 15.35 | 21.19 | 0.9859 | Candidate |
| **Random Forest Regressor** | 15.69 | 21.70 | 0.9852 | Candidate |

*Model persistence is handled cleanly via `joblib` into `models/demand_model.joblib`.*

## 9. Generative AI & Automated Insights Architecture
- **Dual-Mode Insight Engine:**
  - **Cloud LLM Mode:** When `IBM_GRANITE_API_KEY` or `OPENAI_API_KEY` is present in `.env`, the system prompts the LLM strictly with structured computed metrics. The LLM never invents numbers.
  - **Deterministic Rule Engine (Default / Offline):** Automatically analyzes category-level cost disparities (e.g. Meat representing 43% of financial loss), weekend surplus imbalances, weather sensitivity, and rolling Z-score anomalies.
- All outputs are explicitly marked with provenance badges (*Rule-Grounded Intelligence* or *AI-Assisted Insight*).

---

## 10. RAG Knowledge Assistant Architecture
- **Knowledge Documents (`knowledge_base/documents/`):**
  - EPA Food Recovery Hierarchy & Source Reduction Guidelines
  - Institutional Kitchen Waste Prevention & Batch Cooking SOPs
  - Sustainable Cafeteria Operations & Measurement Protocols
  - UN SDG 12, SDG 2, and SDG 13 Integration Briefs
- **Vector Retrieval:** TF-IDF n-gram vectorization with cosine similarity and support for LangChain / ChromaDB embeddings.
- **Source Grounding:** Retrieves top-$k$ relevant passages and displays verbatim document citations and relevance confidence scores.

---

## 11. Responsible AI & Ethical Considerations
- **Human-in-the-Loop:** Predictions and prep buffers are decision-support recommendations. Final kitchen preparation quantities must be approved by human managers.
- **Zero PII:** Operates purely on aggregate shift counts and weights; requires zero diner personal data.
- **Uncertainty Transparency:** Forecasts display 90% confidence bands and dynamic buffer ranges.
- **No Fabricated Claims:** Real-world waste reductions are framed as model simulations and potential savings, never unproven real-world claims.

## 13. Installation & Local Execution

### 1. Clone & Setup Environment
```bash
# Clone the repository
git clone https://github.com/your-username/optimeal-ai.git
cd optimeal-ai

# Create virtual environment (Python 3.10+)
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Environment Configuration (Optional)
```bash
# Copy template
cp .env.example .env
```
*(The application runs fully in offline Demo Mode without any API keys!)*

### 4. Run Feature Pipeline & Train Models
```bash
# Execute ETL & feature engineering
python src/feature_engineering.py

# Train & benchmark ML models
python src/train_demand_model.py
```

### 5. Run Automated Tests
```bash
python -m unittest discover tests
```

### 6. Launch the Streamlit Dashboard
```bash
streamlit run app.py
```

The application will be accessible in your web browser at `http://localhost:8501`.

## 14. Known Limitations & Future Enhancements

### Current Prototype Limitations
- Historical dataset captures summer canteen service (June–August); year-round academic or seasonal variations are simulated.
- Turnstile gate telemetry and weather variables are statistically augmented based on cafeteria capacity.
- Offline RAG uses TF-IDF cosine similarity vectorization when dense neural embeddings / external vector DBs are not configured.

### Roadmap for Future Enhancements
1. **IoT Smart Scale Integration:** Direct telemetry ingestion from kitchen smart waste bins (e.g. Winnow/Leanpath scale integration).
2. **Multi-Item Menu Optimization:** Recipe-level ingredient decomposition (e.g., predicting kilograms of raw chicken breast, basmati rice, and seasonal greens).
3. **Live Weather API Integration:** Automatic real-time precipitation and temperature ingestion from OpenWeatherMap.
4. **Food Rescue API Connectors:** Automated push notifications to local hunger relief charities when surplus exceeds safe threshold.
